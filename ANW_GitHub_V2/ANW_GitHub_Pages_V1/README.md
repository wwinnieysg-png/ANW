# ANW The Arture Hub — Reference Style V2

This package is designed to replace the existing contents of the repository folder:

`ANW_GitHub_Pages_V1`

The GitHub Pages workflow can keep using:

`./ANW_GitHub_Pages_V1`

## Visual changes
- Layout rebuilt to match the supplied editorial reference
- Cinematic hero
- Horizontal About section
- Discover / Create / Connect cards
- Featured Projects / Exhibitions
- Four social media cards
- Collaboration section
- Dark closing statement
- No final logo is assumed

## Interaction changes
- Scroll reveal
- Active navigation
- Scroll progress line
- Hero / closing parallax
- Card tilt
- Image zoom
- Pointer-follow glow
- Magnetic buttons
- Ripple click feedback
- Animated pathway side panel
- Project modal
- Contact modal
- Mobile navigation
- Reduced-motion accessibility support

## Publish update
Overwrite the files inside the existing `ANW_GitHub_Pages_V1` folder in GitHub, then commit to `main`.

GitHub Pages should redeploy automatically through the workflow you already configured.
